# Expense Tracker

A simple web-based expense tracker built with HTML, CSS, and JavaScript.

## Features

- Add expenses with name, amount, category, and date
- View all expenses in a table
- Display the total expense amount
- Filter expenses by category

## Files

- `index.html` - main page layout and form
- `style.css` - styles for the tracker UI
- `script.js` - expense management and filtering logic

## Usage

1. Open `index.html` in a web browser.
2. Add a new expense using the form.
3. View expenses listed in the table.
4. Use the category filter to see specific expense categories.

## Notes

- No backend is included; all data is stored in memory while the page is open.
- Reloading the page will clear the current expense list.
